1. They're automatically generated by `npm run build`
2. The `.gitignore` file correctly excludes them
3. The GitHub Actions workflow builds them automatically
4. Committing them makes the repository huge (1.7+ million lines added!)

## Why This Happens

When `.gitignore` is added in the same commit or after files are already tracked, git doesn't automatically untrack them. The files need to be explicitly removed from git's index using `git rm --cached`.
